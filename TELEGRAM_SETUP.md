# Настройка отправки заявок в Telegram

Этот документ описывает, как настроить отправку заявок с лендинга в Telegram.

## Шаг 1: Создание Telegram бота

1. Откройте Telegram и найдите бота [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Введите имя для вашего бота (например: "МЧС Лицензии Бот")
4. Введите username для бота (должен заканчиваться на `bot`, например: `mchs_license_bot`)
5. **BotFather** отправит вам токен бота. Он выглядит примерно так:
   ```
   1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
   ```
6. **ВАЖНО:** Сохраните этот токен! Он понадобится для настройки.

## Шаг 2: Получение Chat ID

### Вариант 1: Получение личного Chat ID
1. Найдите в Telegram бота [@userinfobot](https://t.me/userinfobot) или [@getmyid_bot](https://t.me/getmyid_bot)
2. Отправьте ему любое сообщение
3. Бот ответит вам вашим ID (это число, например: `123456789`)

### Вариант 2: Получение Chat ID группы
1. Создайте группу в Telegram
2. Добавьте вашего бота в эту группу (через поиск по username)
3. Добавьте бота [@getmyid_bot](https://t.me/getmyid_bot) в эту же группу
4. Бот отправит Chat ID группы (это отрицательное число, например: `-987654321`)
5. После получения ID можете удалить @getmyid_bot из группы

## Шаг 3: Настройка переменных окружения

1. Откройте файл `.env.local` в корне проекта
2. Замените значения на полученные данные:

```env
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
TELEGRAM_CHAT_ID=123456789
```

Для группы Chat ID будет отрицательным:
```env
TELEGRAM_CHAT_ID=-987654321
```

## Шаг 4: Запуск приложения

1. Перезапустите сервер разработки:
```bash
npm run dev
```

2. Откройте сайт на http://localhost:3000

3. Заполните и отправьте форму на сайте

4. Проверьте Telegram - вы должны получить уведомление!

## Формат уведомления

Уведомление в Telegram будет выглядеть так:

```
🆕 Новая заявка с сайта!

👤 Имя: Иван Иванов
📱 Телефон: +7 (999) 123-45-67

📅 Дата: 16.10.2025, 15:30
```

## Устранение неполадок

### Заявка не отправляется
1. Проверьте, что токен бота и Chat ID указаны правильно в `.env.local`
2. Убедитесь, что бот добавлен в группу (если используете групповой чат)
3. Проверьте консоль браузера и терминал на наличие ошибок

### Бот не отвечает
1. Убедитесь, что вы отправили хотя бы одно сообщение боту (`/start`)
2. Проверьте, что бот не заблокирован

### Ошибка "Forbidden"
- Если используете личный чат: отправьте боту команду `/start`
- Если используете группу: убедитесь, что бот добавлен в группу и имеет права на отправку сообщений

## Безопасность

⚠️ **ВАЖНО:**
- Никогда не публикуйте `.env.local` в Git
- Не делитесь токеном бота с посторонними
- Файл `.env.local` уже добавлен в `.gitignore`
- Используйте файл `.env.example` как шаблон для других разработчиков

## Деплой на продакшн

При деплое на Vercel, Netlify или другой хостинг:

1. Добавьте переменные окружения в настройках проекта:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`

2. После добавления переменных сделайте редеплой приложения

## Дополнительные возможности

Вы можете настроить:
- Формат сообщения в файле `src/app/api/send-telegram/route.ts`
- Добавить дополнительные поля в форму
- Настроить уведомления в несколько чатов одновременно
