# Структура компонентов

Этот документ описывает архитектуру компонентов лендинга.

## Структура директорий

```
src/
├── app/
│   ├── page.tsx                    # Главная страница (композиция компонентов)
│   ├── globals.css                 # Глобальные стили
│   └── api/
│       └── send-telegram/          # API для отправки в Telegram
│           └── route.ts
└── components/
    ├── sections/                   # Секции страницы
    │   ├── Header.tsx              # Шапка с навигацией
    │   ├── HeroSection.tsx         # Главная секция с формой
    │   ├── InfoSection.tsx         # Информация о лицензии
    │   ├── AdvantagesSection.tsx   # Наши преимущества
    │   ├── ContactFormSection.tsx  # Форма обратной связи
    │   ├── ContactInfoSection.tsx  # Контактная информация
    │   └── Footer.tsx              # Подвал сайта
    ├── ClientWrapper.tsx           # Клиентская обертка
    ├── FormSubmitContext.tsx       # React Context для форм
    └── ui/                         # UI компоненты
        ├── Logo.tsx                # Логотип компании
        ├── Modal.tsx               # Модальное окно
        └── FloatingCallButton.tsx  # Плавающая кнопка звонка
```

## SSR Оптимизация ⚡

Проект оптимизирован для Server-Side Rendering (SSR). Подробная документация: [SSR_OPTIMIZATION.md](SSR_OPTIMIZATION.md)

**Серверные компоненты (быстрая загрузка):**
- ✅ `page.tsx` - главная страница
- ✅ `InfoSection` - статический контент
- ✅ `ContactInfoSection` - статический контент
- ✅ `Footer` - статический контент

**Клиентские компоненты (только где нужна интерактивность):**
- ⚡ `ClientWrapper` - обертка с логикой форм
- ⚡ `FormSubmitContext` - Context для передачи функций
- ⚡ `Header` - меню с состоянием
- ⚡ `HeroSection` - форма с состоянием
- ⚡ `AdvantagesSection` - интерактивные карточки с hover-состоянием
- ⚡ `ContactFormSection` - форма с валидацией и состоянием
- ⚡ `FloatingCallButton` - модал с состоянием
- ⚡ `Modal` - интерактивный компонент

```

## Компоненты секций

### 1. Header (Шапка сайта)

**Файл:** `src/components/sections/Header.tsx`

**Описание:** Фиксированная шапка сайта с навигацией и CTA кнопкой.

**Особенности:**
- Sticky позиционирование (остается вверху при скролле)
- Адаптивное меню для мобильных устройств
- Якорные ссылки для навигации по секциям
- Мобильное меню с анимацией

**Навигационные ссылки:**
- `#hero` - Главная
- `#info` - О лицензии
- `#advantages` - Преимущества
- `#form` - Заявка
- `#contact` - Контакты

### 2. HeroSection (Главный экран)

**Файл:** `src/components/sections/HeroSection.tsx`

**Props:**
```typescript
interface HeroSectionProps {
  onSubmit: (data: { name: string; phone: string }) => Promise<void>;
}
```

**Описание:** Главная секция с заголовком, описанием и формой быстрой заявки.

**Особенности:**
- Градиентный фон с фоновым изображением
- Две CTA кнопки
- Интегрированная форма заявки
- Обработка состояния загрузки

### 3. InfoSection (Информация о лицензии)

**Файл:** `src/components/sections/InfoSection.tsx`

**Описание:** Секция с информацией о лицензии МЧС, типах работ и видах лицензий.

**Особенности:**
- 3 карточки с изображениями (монтаж, системы, проектирование)
- Hover-эффекты на изображениях (zoom)
- Блок с видами лицензий
- Использует изображения из Unsplash

### 4. AdvantagesSection (Преимущества)

**Файл:** `src/components/sections/AdvantagesSection.tsx`

**Описание:** Секция с преимуществами компании и этапами работы.

**Особенности:**
- 4 карточки преимуществ с иконками
- Блок "Как мы работаем" с 4 этапами
- Фоновое изображение с низкой прозрачностью
- Hover-эффекты на карточках

### 5. ContactFormSection (Форма обратной связи)

**Файл:** `src/components/sections/ContactFormSection.tsx`

**Props:**
```typescript
interface ContactFormSectionProps {
  onSubmit: (data: { name: string; phone: string }) => Promise<void>;
}
```

**Описание:** Основная форма обратной связи с градиентным фоном.

**Особенности:**
- Градиентный синий фон
- Glassmorphism эффект на инпутах
- Валидация полей
- Обработка состояния отправки

### 6. ContactInfoSection (Контактная информация)

**Файл:** `src/components/sections/ContactInfoSection.tsx`

**Описание:** Секция с контактной информацией компании.

**Особенности:**
- 3 карточки контактов (телефон, email, адрес)
- Блок с социальными сетями
- Кликабельные ссылки (tel:, mailto:)
- Иконки SVG

### 7. Footer (Подвал)

**Файл:** `src/components/sections/Footer.tsx`

**Описание:** Подвал сайта с дополнительной информацией.

**Особенности:**
- 3 колонки информации
- Логотип компании
- Список услуг
- Контактная информация
- Copyright

## UI компоненты

### Logo (Логотип)

**Файл:** `src/components/ui/Logo.tsx`

**Описание:** Компонент логотипа компании с изображением и названием.

**Особенности:**
- Использует Next.js Image для оптимизации
- Поддерживает пользовательское изображение
- Адаптивный размер

### Modal (Модальное окно)

**Файл:** `src/components/ui/Modal.tsx`

**Props:**
```typescript
interface ModalProps {
  isOpen: boolean;
  onClose: () => void;
  children: React.ReactNode;
}
```

**Описание:** Универсальное модальное окно для отображения контента поверх страницы.

**Особенности:**
- Блокировка скролла страницы при открытии
- Закрытие по клику на overlay (затемненный фон)
- Закрытие по нажатию клавиши Escape
- Плавная анимация появления (scale-in)
- Кнопка закрытия в правом верхнем углу
- Backdrop blur эффект

### FloatingCallButton (Плавающая кнопка звонка)

**Файл:** `src/components/ui/FloatingCallButton.tsx`

**Props:**
```typescript
interface FloatingCallButtonProps {
  onSubmit: (data: { name: string; phone: string }) => Promise<void>;
}
```

**Описание:** Плавающая кнопка в правом нижнем углу для быстрого заказа звонка.

**Особенности:**
- Фиксированная позиция (bottom-6 right-6)
- Круглая кнопка (16x16) с иконкой телефона
- Градиентный фон (blue-600 to blue-700)
- Анимация bounce-slow (плавное покачивание)
- Pulse-эффект (расширяющиеся круги)
- Hover-эффекты (увеличение scale-110)
- Модальное окно с формой обратного звонка
- Z-index: 50 (всегда поверх контента)

**Поведение:**
1. Кнопка всегда видна на всех страницах
2. При клике открывается модальное окно
3. В окне отображается форма с полями:
   - Имя (обязательное)
   - Телефон (обязательное)
4. Заголовок: "Заказать звонок"
5. Подзаголовок: "Оставьте свой номер и мы перезвоним вам в течение 15 минут"
6. После отправки форма очищается и окно закрывается автоматически

**Анимации:**
- `bounce-slow` - плавное покачивание кнопки (3s)
- `animate-ping` - пульсация фона
- `scale-110` - увеличение при наведении

## Главная страница (Композиция)

**Файл:** `src/app/page.tsx`

**Описание:** Главная страница собирает все секции вместе.

**Функции:**
- `handleFormSubmit` - обработчик отправки форм
- Отправляет данные на `/api/send-telegram`
- Показывает уведомления пользователю

**Структура:**
```tsx
<div>
  <Header />
  <HeroSection onSubmit={handleFormSubmit} />
  <InfoSection />
  <AdvantagesSection />
  <ContactFormSection onSubmit={handleFormSubmit} />
  <ContactInfoSection />
  <Footer />
  <FloatingCallButton onSubmit={handleFormSubmit} />
</div>
```

## Принципы разработки

### 1. Разделение ответственности

Каждая секция — отдельный компонент с собственной логикой и стилями.

### 2. Переиспользуемость

UI компоненты (Logo) могут использоваться в разных местах.

### 3. Props для взаимодействия

Формы принимают `onSubmit` callback для гибкости.

### 4. Client Components

Компоненты с интерактивностью помечены `'use client'`.

## Как редактировать

### Изменить контент секции

1. Откройте нужный файл компонента
2. Измените текст, ссылки или данные
3. Сохраните файл

### Добавить новую секцию

1. Создайте файл `src/components/sections/NewSection.tsx`
2. Экспортируйте компонент
3. Импортируйте в `src/app/page.tsx`
4. Добавьте компонент в нужное место

Пример:
```tsx
// src/components/sections/NewSection.tsx
export default function NewSection() {
  return (
    <section id="new-section" className="py-20">
      {/* Ваш контент */}
    </section>
  );
}

// src/app/page.tsx
import NewSection from '@/components/sections/NewSection';

export default function Home() {
  return (
    <div>
      <Header />
      {/* ... другие секции ... */}
      <NewSection />
      <Footer />
    </div>
  );
}
```

### Изменить навигацию

Откройте `src/components/sections/Header.tsx` и измените массив `navLinks`:

```tsx
const navLinks = [
  { href: '#hero', label: 'Главная' },
  { href: '#new-section', label: 'Новая секция' }, // добавить
  // ...
];
```

### Настроить формы

Обе формы используют один обработчик `handleFormSubmit` в `src/app/page.tsx`. Чтобы изменить логику отправки, отредактируйте эту функцию.

## Стилизация

Все компоненты используют Tailwind CSS:
- Utility-first подход
- Адаптивные классы (`md:`, `lg:`)
- Темная тема отключена (светлая тема)
- Основной цвет: синий (`blue-600`, `blue-700`)

## Оптимизация

- **Code splitting** - каждый компонент загружается отдельно
- **Tree shaking** - неиспользуемый код не попадет в бандл
- **Image optimization** - Next.js Image для логотипа
- **CSS optimization** - Tailwind удаляет неиспользуемые стили

## Тестирование

Для тестирования компонентов:

1. Запустите dev сервер: `npm run dev`
2. Откройте http://localhost:3000
3. Проверьте каждую секцию
4. Протестируйте формы
5. Проверьте адаптивность на разных экранах
