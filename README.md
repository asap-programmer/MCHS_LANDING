# Лендинг "Лицензия МЧС под ключ"

Современный лендинг для услуг по получению лицензии МЧС. Создан на Next.js 15 с использованием React 19 и Tailwind CSS.

## Особенности

- ✅ Современный адаптивный дизайн
- ✅ Светлая тема с синими акцентами
- ✅ Формы обратной связи с отправкой в Telegram
- ✅ Плавающая кнопка звонка с модальным окном
- ✅ Изображения из бесплатного стока (Unsplash)
- ✅ Плавные анимации и hover-эффекты
- ⚡ **SSR оптимизация** - быстрая загрузка страницы
- 🔍 SEO-оптимизация
- ✅ TypeScript для надежности кода

## Структура лендинга

1. **Header** - Логотип и кнопка CTA
2. **Hero Section** - Главный экран с формой быстрой заявки
3. **Info Section** - Информация о лицензии и видах работ
4. **Advantages** - Наши преимущества и процесс работы
5. **Contact Form** - Форма обратной связи
6. **Contact Info** - Контактная информация
7. **Footer** - Подвал с информацией о компании

## Быстрый старт

Установите зависимости:

```bash
npm install
# или
pnpm install
```

Настройте Telegram бота (см. [TELEGRAM_SETUP.md](TELEGRAM_SETUP.md)):

```bash
cp .env.example .env.local
# Отредактируйте .env.local и добавьте ваши данные
```

Запустите сервер разработки:

```bash
npm run dev
# или
pnpm dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## Настройка Telegram уведомлений

Для получения заявок в Telegram необходимо:

1. Создать бота через [@BotFather](https://t.me/BotFather)
2. Получить Chat ID через [@userinfobot](https://t.me/userinfobot)
3. Настроить переменные окружения в `.env.local`

Подробная инструкция: [TELEGRAM_SETUP.md](TELEGRAM_SETUP.md)

## Архитектура

Проект построен на компонентной архитектуре с SSR оптимизацией:
- **Декомпозиция** - каждая секция вынесена в отдельный компонент
- **Переиспользуемость** - UI компоненты можно использовать многократно
- **Навигация** - Header содержит якорные ссылки для перехода между секциями
- **Модульность** - легко добавлять, удалять или изменять секции
- ⚡ **SSR** - серверный рендеринг для быстрой загрузки

### Оптимизация производительности:

Большинство компонентов рендерятся на сервере (помечены SSR):
- ✅ Статический контент загружается мгновенно
- ⚡ JavaScript только там, где нужна интерактивность
- 🔍 Лучшее SEO благодаря серверному рендерингу
- 📱 Быстрая загрузка на мобильных устройствах

## Деплой

### Vercel (рекомендуется)

1. Загрузите проект на GitHub
2. Импортируйте проект в [Vercel](https://vercel.com)
3. Добавьте переменные окружения:
